# Источники звуков

Все записи распространяются по лицензии CC0 (общественное достояние).
Файлы обрезаны, выровнены по громкости и перекодированы для сайта.

## Звуки действий

- ui-click, ui-click-2, tick, switch, undo, redo —
  Kenney, «Interface Sounds» (click_001, click_005, tick_004, switch_006, back_002, back_004)
  https://kenney.nl/assets/interface-sounds
- paper-open, paper-close, paper-flip-1, paper-flip-2, sticker, rustle, pin —
  Kenney, «RPG Audio» (bookOpen, bookClose, bookFlip2, bookFlip3, cloth2, cloth1, bookPlace1)
  https://kenney.nl/assets/rpg-audio

## Атмосфера

- ambience-wind — Luke.RUSTLTD, «wind1» (wind1.wav), синтезированный ветер
  https://opengameart.org/content/wind1
- ambience-hum — JaggedStone, «Loopable Dungeon Ambience», низкий гул с каплями
  https://opengameart.org/content/loopable-dungeon-ambience
- ambience-storm — WuxiaScrub, «Rain + Long Thunder» (rain-thunder.ogg);
  дождь зациклен, гром вмешан дважды с пониженной громкостью
  https://opengameart.org/content/rain-long-thunder
